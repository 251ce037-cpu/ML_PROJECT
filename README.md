# 🧬 Genetic Disorder Prediction System

## 📌 Project Overview
The Genetic Disorder Prediction System is a Python-based machine learning project focused on exploring genetic disorder prediction using data analysis and machine learning techniques.

This project includes a collection of seven project components, along with reports and supporting Python files.

## 🎯 Objectives
- Explore machine learning techniques for genetic disorder prediction.
- Understand data analysis and preprocessing.
- Organize different project components.
- Explore the application of machine learning in healthcare.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- XGBoost
- Flask
- Streamlit

## 📊 Project Aim
To explore how machine learning and data analysis techniques can be applied to genetic disorder prediction.
